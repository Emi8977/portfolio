# Emiliano Luna - Portfolio Specification

## 0. Note

- If you do not know how to create a portfolio, here are the criteria I used to build mine. It is brief, simple, and goes straight to what you need.

## 1. Overview

- Project name: Emiliano Luna Portfolio
- Type: personal portfolio / landing page for a Full Stack Developer

## 2. Main sections

### Header / navigation
- Fixed navigation bar
- Brand: Emiliano Luna
- Links to: About me, Development, Projects, Contact
- Mobile menu for small screens

### Hero
- Brief introduction of the developer
- Main title: Emiliano Luna / Full Stack Developer
- Main actions: View Projects / Contact
- Minimal decorative code-style elements
- Dark design with contrast accents and technical personality

### About me
- Personal summary with professional background and focus
- Emphasis on software development, analysis, and problem solving
- Showcase of the technology stack and technical vision

### Development / services
- Description of work areas such as full-stack development, digital products, platforms, and customized applications
- Cards with clear value and focus

### Projects
- Presentation of featured work and applications developed
- Each project can include:
  - title
  - brief description
  - technology tags
  - access link
  - visual preview or screenshot view
- Grid/card layout with clear visual hierarchy

### Contact
- CTA section for business or collaboration inquiries
- Direct contact button/modal or link
- References to email and social networks

### Footer
- Brief branding and copyright
- Quick navigation and contact reference

## 3. UX / UI requirements

### Visual direction
- Dark / matte black background
- Navy / dark blue cards and sections
- Subtle grid for design texture
- Clean, modern typography with a technical feel
- High contrast between text and backgrounds
- Moderate use of color to highlight key elements

### Typography
- Headings: modern, technical, and clear
- Body: readable sans-serif
- Code-style labels and tags with technical identity

### Layout behavior
- One-page experience
- Sections organized vertically with smooth navigation
- Responsive design for mobile, tablet, and desktop
- Maintain spacing and proportions without breaking the original structure

### Interactions
- Anchor navigation with smooth scrolling
- Hover states on cards and buttons
- Element reveal on scroll
- Expandable stack or project actions when applicable
- Modals or contact interactions

## 4. Technical stack

- React 18
- Vite
- JavaScript
- Custom CSS
- External resources for logos, screenshots, and previews
- EmailJS for contact
