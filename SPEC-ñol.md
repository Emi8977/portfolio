# Especificación del Portfolio - Emiliano Luna

## 0. Nota

- Si no sabes como hacer un portfolio, te dejo estos criterios que tomé para hacer mi portfolio, es breve y simple, va directo a lo necesitas.

## 1. Visión general

- Nombre del proyecto: Portfolio de Emiliano Luna
- Tipo: portfolio personal / landing page para desarrollador Full Stack

## 2. Secciones principales

### Header / navegación
- Barra fija de navegación
- Marca: Emiliano Luna
- Links hacia: Sobre mí, Desarrollo, Proyectos, Contacto
- Menú móvil para pantallas pequeñas

### Hero
- Presentación breve del desarrollador
- Título principal: Emiliano Luna / Full Stack Developer
- Acciones principales: Ver Proyectos / Contactar
- Elementos decorativos minimalistas tipo código
- Diseño oscuro con acentos de contraste y personalidad técnica

### Sobre mí
- Resumen personal con formación y enfoque profesional
- Enfoque en desarrollo de software, análisis y resolución de problemas
- Muestra del stack y visión técnica

### Desarrollo / servicios
- Descripción de áreas de trabajo como desarrollo full stack, productos digitales, plataformas y apps personalizadas
- Cards con un texto claro sobre valor y enfoque

### Proyectos
- Presentación de trabajos destacados y aplicaciones desarrolladas
- Cada proyecto puede incluir:
  - título
  - descripción breve
  - etiquetas tecnológicas
  - enlace de acceso
  - vista visual de capturas o previews
- Distribución en grid/cards con jerarquía visual marcada

### Contacto
- Sección de CTA para consultas de negocio o colaboración
- Botón/modal o enlace de contacto directo
- Referencias a email y redes

### Footer
- Marca breve y copyright
- Navegación rápida y referencia de contacto

## 3. Requisitos de UX/UI

### Dirección visual
- Fondo oscuro / negro mate
- Cards y secciones en azul marino / navy
- Cuadrícula sutil para textura del diseño
- Tipografía limpia y moderna con apariencia técnica
- Alto contraste entre texto y fondos
- Uso moderado de color para resaltar elementos clave

### Tipografía
- Encabezados: estilo moderno, técnico y claro
- Cuerpo: sans-serif legible
- Labels tipo código y tags con identidad técnica

### Comportamiento del layout
- Experiencia tipo one-page
- Secciones organizadas verticalmente con navegación suave
- Diseño responsive para móvil, tablet y desktop
- Mantener spacing y proporciones sin romper la estructura original

### Interacciones
- Navegación mediante anclas con desplazamiento suave
- Hover states sobre cards y botones
- Revelado de elementos al hacer scroll
- Acciones expandibles de stack o proyectos cuando corresponde
- Modales o interacciones de contacto

## 4. Stack técnico

- React 18
- Vite
- JavaScript
- CSS personalizado
- Recursos externos para logos, screenshots y previews
- EmailJS para contacto
