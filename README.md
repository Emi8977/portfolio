# Emiliano Luna | Portfolio

Mi Portfolio personal, desarrollador Full Stack con enfoque en aplicaciones web, productos digitales y soluciones funcionales para negocios y proyectos reales.

## Descripción

Este proyecto es una landing page / portfolio profesional construida con React + Vite, diseñada para presentar:

- información personal y perfil profesional
- stack tecnológico y capacidades
- servicios de desarrollo
- proyectos destacados con detalle de soluciones implementadas
- contacto directo para oportunidades, colaboraciones o proyectos

La identidad visual se enfoca en una estética moderna, oscura y técnica, con cards en azul marino, fondo negro mate, grid sutil y una experiencia orientada a presentar trabajo con claridad y personalidad.

## Objetivo

Mostrar la experiencia, el trabajo y la forma de abordar proyectos como desarrollador.

## Stack principal

- React
- Vite
- JavaScript
- CSS Modules / CSS custom
- EmailJS para contacto
- Assets locales y recursos remotos para proyectos y logos

## Secciones principales

- Hero / presentación
- Sobre mí
- Desarrollo / servicios
- Proyectos
- Contacto
- Footer

## Requisitos y ejecución local

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
